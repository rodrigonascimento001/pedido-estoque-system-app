# harden-order-kafka-consistency

Corrigir consistência entre pedido, estoque e Kafka com reserva atômica e idempotente, transactional outbox, transições de estado protegidas e visibilidade da DLT. Segurança, precificação, idempotência HTTP, replay da DLT e hardening de mensagens/topologia Kafka ficam no backlog para changes seguintes.
